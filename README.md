# github-final-project

## Simple Interest Calculator

This project contains a simple interest calculator implemented as a Bash shell script. It takes the principal amount, rate of interest, and time period as inputs and calculates the simple interest.

## Formula

**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal (P)** is the initial amount of money.
- **Rate (R)** is the annual rate of interest in percent.
- **Time (T)** is the time period, typically in years.

## How It Works

The calculator asks the user to enter the principal amount, rate of interest, and time period. It then applies the simple interest formula and displays the calculated interest.

## Example

**Input:**
- Principal: 10000
- Rate of Interest: 5%
- Time: 2 years

**Output:**
- Simple Interest: 1000.00

## Files

- `simple-interest.sh` — Bash script that calculates simple interest from user-provided values.
